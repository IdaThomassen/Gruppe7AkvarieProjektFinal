# Gruppe7AkvarieProjektFinal

Dette er her vi laver vores kode til akvarie projektet gruppe 7
Gruppen består af Mathilde, Josephine, Benjamin og Ida

Der er lavet kommentar med hvem der har lavet hvad på de forskellige html, CSS og Javascript filer

Index:
Index / forsiden er lavet mest af Benjamin, Josephine og Ida

JavaScript:
JavaScript for fiskene er lavet i fællesskab
JavaScript for boblerne er lavet af Josephine og Ida
JavaScript for lukke knappen (rødt kryds) er lavet af Josephine og Ida

CSS:
Typografi er lavet af Josephine
Info boks er lavet af Josephine og Ida
Baggrunden er lavet med hjælp fra Per
Fiskenes animationer er skrevet af hver enkelt person, men lavet i fællesskab
Animation af karusellen / boblerne er lavet af Benjamin, Josephine og Ida
CSS af lukke knappen (rødt kryds) er lavet af Josephine og Ida
CSS for spil billederne er lavet af Josephine og Ida

Info om fisk (klik på fiskene):
Vi startet med at lave en side i fællesskab, derefter har Josephine og Ida lavet resten
Siderne om fiskene er bygget op som en ny underside. De har alle samme stil.
Siden består af en baggrund (scene), en overskrift (h3), paragrafer med tekst (p), kryds i hjørnet (lukke knap) og et billede af fisken. Siden er forbundet med JavaScript og CSS

Spil bobler:
Vi valgte at lave nogle af boblerne til spilene. Stilen er den sammen for alle spil.
Spil siderne består af en baggrund (scene), en overskrift (h2), et billedet af spillet (img), kryds i hjørnet (lukke knap) og en hjørne boble. Siden af forbundet med JavaScript og CSS
